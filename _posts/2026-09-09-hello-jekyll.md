title: Hello, Jekyll
---

This is the first post. Posts live in the `_posts` folder and their filename must start with a date, like `2026-09-09-hello-jekyll.md`. Jekyll reads the date from the filename and sorts posts newest first.

Markdown works as expected:

- Lists
- **Bold** and *italic*
- [Links](https://jekyllrb.com)

And so do code blocks:

```ruby
puts "Hello from Jekyll"
```

To publish a new post, add another file to `_posts` and push.
