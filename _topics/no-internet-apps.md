Every app in this section is built to run without an internet connection. Not "works offline until it needs to sync", but genuinely standalone: no account, no server, no phone-home. You could copy one onto a floppy disk, hand it to a friend, and it would work exactly the same on their machine as on yours.

That choice has one consequence worth knowing about. There is no auto-update. An app that never talks to the internet cannot find out that a newer version exists, so it will not tell you. Each app page shows its current version number. Check back here from time to time, compare it with the one you have, and download the new one if you want it.

But who needs updates when things work?
